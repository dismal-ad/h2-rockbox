Wi-Fi files for the H2 (CYW43438 in the AzureWave AW-NM372SM module)

cyfmac43430-sdio.bin        chip firmware 7.45.98.118 (Cypress, from linux-firmware)
cyfmac43430-sdio.clm_blob   regulatory data for that firmware (linux-firmware)
nvram.txt                   board calibration: brcmfmac43430-sdio.AP6212.txt from
                            linux-firmware (a CYW43438 module with a 26 MHz
                            crystal, as the H2's module has)

cacert.pem                  Mozilla's root certificates (Debian ca-certificates),
                            for HTTPS
networks.txt                saved networks, written by the player:
                            <name> TAB <security> TAB <password>
